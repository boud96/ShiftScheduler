# Shift Scheduler, Phase 1: decisions and open items

These notes keep what the Phase 1 build decided on the user's behalf, and what it left for later. They come from the build's working ledger, which was not kept in git. Where a ruling differs from the plan (`2026-11-04-shift-scheduler-phase-1.md`) or the spec, the ruling describes what was built.

Two of the rulings go beyond the spec:
- R51: the rule engine also reads each person's stored code on the next month's day 1. A night before a stored request there, or too little rest before a stored shift there, is flagged on the month's last day, so the generator avoids it.
- R58: the W3 and W8 messages differ from the plan's table.

## Rulings (R1–R64; R7 was not used)

Each ruling says what was decided, why, and what it costs if the decision was wrong.
